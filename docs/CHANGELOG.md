# 变更记录

## v2（2026-11）

### 修复

- 认输只在本地生效：现在通过 `RESIGN` 双端结算
- 悔棋可在他方回合发起、可撤销对手胜局：改为按申请方颜色精确回退，限次、终局后禁用
- 围棋悔棋不恢复提子/劫：改为截断历史后完整回放
- 围棋无超级劫、死子未处理：补位置超级劫、点目阶段与死子标记
- 心跳只发不收：补 PONG 超时判定与 60 秒重连窗口
- 加入房间靠猜模式：改为握手校验，模式不匹配时明确拒绝并自动切换
- 第二条连接顶掉第一条：房主拒绝并提示房间已满
- 消息无版本/序号/校验：补协议版本、序号去重、字段校验、重同步
- 对话框靠文案判类型：改为显式请求对象
- 再来一局单方生效：改为请求/同意
- AI 无请求 id 与时间上限：补请求取消、时间预算与思考状态
- 威胁识别误报、胜率模型不合理：重写棋型识别与评估
- 提示坐标与棋盘标注上下颠倒：统一记谱
- 手机端棋盘发虚、无法触控：补 DPR、ResizeObserver、Pointer 事件
- 原生 `alert/confirm`：替换为统一模态与 Toast
- README 的“双击 index.html 可玩”：更正为 `npm run dev`（`file://` 下 ES Module/Worker 被拦截）
- `init` 与重建逻辑重复、`*` 辅助后缀残留：重构控制器并移除隐式权限

### 新增

- 人机对战（五子棋 / 围棋，三档难度）
- 围棋 9/13/19 路与贴目设置
- 断线重连与状态重同步
- 深链邀请 `?room=CODE&mode=...`
- 走子记录列表、提子/贴目信息、本地战绩
- 落子/胜利音效、动画、胜线高亮
- 键盘操作、焦点陷阱、`prefers-reduced-motion`
- Node 单测、ESLint、GitHub Actions、本地静态服务器

### 移除

- 旧的 `ai.js` / `ai-eval.js` / `ai-worker.js` / `go-ai-eval.js` / `webrtc.js`（被 `js/ai/*` 与 `js/net/*` 取代）
- 隐藏作弊按键序列（改为可配置的 AI 辅助）

### 结构

- 规则抽取为 `js/rules/*`，状态机不再依赖 DOM
- 网络拆分为传输 / 协议 / 会话
- 渲染与控制器分离
